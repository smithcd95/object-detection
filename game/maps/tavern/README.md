# Tavern interior

`tavern_688x384.png`: PixelLab Create Image Pro (688x384, 25 generations), layout reference = a painted isometric
tavern interior, style image = a cottage crop of `../lighthouse_village/section_01.png`. Full 1:1 pixel detail
(about 40% flat 2x2 blocks, same as the village section), matching the baker sprite's scale.

`tavern_full_560x448.png`: the whole room as a cutaway (transparent around it), from a full-room painted
reference with a crop of `tavern_688x384.png` as the style image (560x448, 25 generations). Furniture is
about 0.65x the size of the first version, so the baker is drawn at 100% here (equivalent to 145% before).
This is the tavern used by `world.html`.
