# Lighthouse village (starter area concept)

Generated with PixelLab Create Image Pro from a layout reference photo (lighthouse cliff village)
and a style reference (`style_reference.png`, an isometric ruined arch, downsampled to its native pixel grid).

- `option1_256.png`, `option2_256.png`: 256x256 concept options.
- `village_512.png`: option 2 remade at full size (512x512).

## Full-detail section tests (512x512, the plaza/stairs area)
- `section_try1_512.png`: crop of `village_512.png` enlarged 2x as layout reference, village crop as style. Traced the blocks, no added detail.
- `section_try2_512.png`: smooth-enlarged crop, baker as style, village palette. Slightly cleaner, still mostly 2x2 blocks.
- `section_photo_baker_style_512.png`: crop of the ORIGINAL painted photo as layout reference, baker as style. True 1:1 pixel
  detail matching the baker sprite. This is the recipe to use for the rest of the area.
