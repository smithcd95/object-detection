# Old Baker sprite

Pixel-art character generated with [PixelLab](https://pixellab.ai) (Pro mode, 80x80 px, low top-down view).
Design based on a pixel daily by @Gerickos, reworked as a baker.

## Contents
- `rotations/` – static pose for 8 directions (south, south-east, east, north-east, north, north-west, west, south-west)
- `animations/idle/<direction>/` – 4-frame breathing idle
- `animations/walk/<direction>/` – 6-frame walk cycle
- `spritesheet/Old_Baker-Idle.png` + `.json` – all frames on one uniform grid, with layout data
- `previews/` – contact sheets (rows = directions in the order above)
- `metadata.json` – PixelLab export metadata

All frames are 80x80 PNG with transparency.
