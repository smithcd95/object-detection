# Old Mechanic sprite

PixelLab character (Pro mode, 80x80, low top-down, 8 directions), designed from concept art by the artist
signed "Death + Milk", with the Old Baker (`../old_baker`) as the style character so both share the same
pixel style, outline, shading and scale. Character id: 9fc8dc6d-3ba1-4870-81af-c1b3a0036f85.

- `rotations/`: static pose for each of the 8 directions.
- `previews/rotations_vs_baker.png`: all 8 directions (top) next to the baker (bottom).
No animations yet.
